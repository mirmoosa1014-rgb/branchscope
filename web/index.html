03 / READ THE LIMITS

This is a controlled experiment, not a CPU performance claim. Traces are synthetic. Predictors update immediately after each branch; speculation, pipeline timing, energy, and real instruction mixes are outside this model.

The same byte ceiling does not imply equal used storage. Table rounding, history registers and 8-bit perceptron weights are included in the displayed bit counts. Python object memory is not a silicon area estimate.

Random sources and distractors intentionally dilute the delayed workload's total gain. Inspect per-site counts in the exported JSON. A successful target prediction cannot make random source branches predictable.
